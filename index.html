Не отправлено

Записи лежат в этом браузере и уйдут сами, когда появится сеть.
Выгрузка собирает весь текст в один файл. Снимки в него не влезут: дневник целиком, вместе с ними, скачивается с GitHub кнопкой Code → Download ZIP.

Темы

Темами распоряжаетесь только вы. Вечерний прогон кладёт заметки только в готовые темы, а если не понял куда, то в запасную. Названия любые, хоть английские.

Синхронизация задач

Для импорта подойдёт скачанный файл задач, backlog.json или stale.json. Совпадающие карточки останутся как в текущем списке.
